Título

Sistema de Neuroevolución Basado en NEAT para la Optimización Automática de Estrategias de Trading Algorítmico mediante Aprendizaje Evolutivo Multiobjetivo

Objetivo General

Desarrollar un sistema basado en algoritmos genéticos y neuroevolución capaz de descubrir automáticamente estrategias de trading rentables y robustas mediante la evolución simultánea de:

Arquitectura de la red neuronal.
Conexiones neuronales.
Pesos.
Selección de indicadores técnicos.
Parámetros de gestión del riesgo.
Umbrales de decisión.

Todo ello validado mediante Walk-Forward Analysis para minimizar el sobreajuste temporal.

Hipótesis

Una estrategia de trading evolucionada mediante neuroevolución, considerando simultáneamente arquitectura neuronal, gestión del riesgo y selección automática de variables, puede obtener un desempeño más robusto fuera de muestra que una estrategia diseñada manualmente.

Fitness

No se entrena con Backpropagation.

Toda la inteligencia surge de la evolución.

Función Fitness

Fitness=0.30S+0.20So+0.15C+0.15PF+0.10WR−0.25DD−0.10OT

Donde

S = Sharpe

So = Sortino

C = Calmar

PF = Profit Factor

WR = Win Rate

DD = Drawdown máximo

OT = Overtrading

También agregaría

if operaciones < 10:
    fitness -= 100

if rentabilidad < 0:
    fitness -= 100

if drawdown > 0.30:
    fitness -= 100

if profit_factor < 1:
    fitness -= 100

Así se eliminan individuos inviables rápidamente.

Evitar Overfitting

El proyecto debe incorporar explícitamente medidas contra los sesgos más comunes:

Walk-Forward Validation.
Datos Out-of-Sample.
Penalización por complejidad (redes demasiado grandes).
Costos reales de transacción.
Slippage.
Restricciones de liquidez.
Normalización usando sólo información disponible hasta el instante actual.
Separación estricta entre entrenamiento y prueba para evitar fuga de información (data leakage).

Posibles extensiones

Una vez completada la versión base, podrías ampliar el proyecto con:

Optimización multiobjetivo mediante NSGA-II, buscando simultáneamente maximizar rentabilidad y minimizar drawdown.
Coevolución de agentes especializados (por ejemplo, uno para mercados alcistas y otro para mercados bajistas).
Sustituir la red densa por una LSTM o una Transformer para capturar dependencias temporales más largas.
Aprendizaje continuo (online learning), permitiendo que la población siga evolucionando con datos nuevos.
Evolución de un portafolio completo con múltiples activos y asignación dinámica de capital.
